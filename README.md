# IoT-Based-Dual-Relay-Control-Using-NodeMCU-and-Kiwisiot
IoT-Based Dual Relay Control using NodeMCU ESP8266 and a 2-channel relay module with independent remote ON/OFF control through the KiwisIoT platform over Wi-Fi.
IoT-Based Dual Relay Control Using NodeMCU ESP8266 and KiwisIoT
About the Project
The IoT-Based Dual Relay Control is an IoT-based project designed to control two electrical devices independently through a Wi-Fi connection.

Using a NodeMCU ESP8266 microcontroller and a 2-channel relay module, the system allows users to turn two connected devices ON and OFF remotely through the KiwisIoT platform. Users can control each relay independently using an online dashboard, making it useful for smart home automation and wireless electrical device control.

By integrating KiwisIoT, this project demonstrates a simple and effective approach to remote device management, wireless switching, and IoT-based automation.
